# Kane E-style comparison preview

Open `?characterPreview=1` on the local Vite development server. The stage shows live Detective V2 beside the E-style Kane idle/walk prototype. WASD and arrow keys move both together at the existing interior speed (235 px/s horizontally, 145 px/s in shallow depth); stopping returns E-style Kane to the unchanged static idle PNG. V2 keeps its `162 / 220` scale and about 162-pixel visible height. E-style uses the separate `E_STYLE_IDLE_SCALE = 145 / 162` constant for about 145 world pixels. Both anchor source row 240 to the same world foot line. The original contact sheet remains in the adjacent reference panel. The scene has no game session, interactions, notebook, or save writes. Remove the query parameter for the unchanged playable game. The query flag is ignored in production builds.

To test E-style Kane against the Bellweather production illustration, open `?lobbyPreview=1&production=1&kaneIdle=1`. The existing `kaneIdle=1` flag now loads the approved six-frame walking cycle and static idle through the same `PlayerVisual` configuration as the comparison stage. The preview retains its separate floor and desk-body collision, camera behavior, artwork depth sorting, and optional `&debug=1` overlay. If the walking sheet is unavailable, the old static idle remains the fallback; if both E-style assets are unavailable, V2 remains visible. The normal production-art preview and playable lobby still show V2.

`kane-e-style-idle-preview.png` is a 256 × 256 transparent RGBA8 PNG. Its visible bounds at alpha ≥ 128 are x=80–174, y=78–239, approximately 162 source pixels tall. At the new `145 / 162` scale, it appears about 145 world pixels tall, versus V2's unchanged 162. The sole row and horizontal center remain aligned with V2. Of 10,280 nontransparent pixels, 9,260 have alpha ≥ 240; the many near-opaque pixels are not evidence of a ghosted character. Inspect the softer edge pixels against dark hotel art during visual review.

The delivered `style-e/walk.png` is an untrimmed 1536 × 256 RGBA8 sheet with six consecutive 256 × 256 right-facing frames (0–5). At alpha ≥ 128, every frame begins at y=78 and reaches sole row 239; x bounds stay within 79–176 in each cell. The preview plays all six at a nominal 12 FPS. A starting two-step stride estimate of 132 source pixels (about 118 world pixels) makes the existing distance-matched animation controller play approximately 11.9 FPS at 235 px/s, and proportionally slower at reduced or vertical movement speed. This is a calibration for visual review, not a measured ground-contact displacement. The controller changes idle/walk only on a state transition, so sustained movement does not restart the clip. Leftward movement mirrors the sprite without changing its foot position.

The walking art natively faces right while the approved three-quarter idle reads left. `eStyleWalkPreviewConfig` now records `idleSourceFacing: -1` separately from the walk's `sourceFacing: 1`. The presentation controller retains the latest nonzero horizontal input direction and recomputes texture mirroring on both direction changes and idle/walk changes. Thus rightward walk and rightward idle both face right (with the idle mirrored), while leftward walk and leftward idle both face left (with the walk mirrored). This affects only the isolated comparison configuration; V2's default same-orientation setting is unchanged. The idle's three-quarter camera angle remains an artwork characteristic.

The six-frame animation is loaded **only** by the isolated character comparison and explicitly flagged Bellweather production previews. Both use the same 145-pixel scale, 240/256 foot origin, movement-matched cadence, and per-clip facing rules. The Bellweather preview positions the animated foot anchor at the existing player world coordinate and depth-sorts it against the production desk. Its debug overlay distinguishes the active desk rectangle from proposed obstacles. Detective V2 remains the playable character.

The right panel is **only a visual reference**. `kane-style-e-reference.png` is 1536 × 1024, 8-bit RGB. Its checkerboard is baked into the pixels, and the poses are arranged with irregular spacing and size. The image does show a front idle study, side/back views, and multiple right-facing walk studies, but it has no transparency or consistently aligned frame cells. Cropping those cells directly would carry the checkerboard and misaligned feet into the game. The new idle PNG is a separate transparent export; this preview does not claim to animate the redesign.

## Art review and future work

- The current `public/assets/characters/kane/references/kane-e-style-idle-preview.png` supplies a usable single static idle pose. It remains an isolated preview asset until its scale and edge treatment are approved.
- The walking PNG now supplies six aligned frames. Review the 5→0 loop seam and idle→walk transition in motion before accepting the art and cadence for gameplay. The static idle faces more toward the viewer than the walk; a matching side idle could improve this later.
- Keep the hat, coat, face, tie, body size, horizontal center, and sole baseline consistent across any later revisions. The current walk matches the idle's y=78–239 visible height; no per-frame offsets, rescaling, checkerboard removal, or synthesized in-betweens were applied.

The walk is isolated behind its own sprite configuration and uses the existing `PlayerVisual`/animation controller. V2 remains the playable default and comparison baseline.
